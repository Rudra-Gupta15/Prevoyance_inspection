                                    How to Use the Network Scanner
                                    
Follow these simple steps to
                                        discover, inspect, and audit network devices

                                

                            

                            ▼ Show Guide
                        


                        

                            

                                

                                    

                                        Step 1: Enter Subnet

                                    
Type your network
                                        IP range in CIDR format (e.g., 192.168.1.0/24 or
                                        10.0.0.0/24).

                                

                                

                                    

                                        Step 2: Set Timeout

                                    
Choose 400ms
                                            (Balanced) for fast scans, or 800ms if scanning firewalled hosts.
                                    

                                

                                

                                    

                                        Step 3: Run Discovery

                                    
Click Start
                                            Scan. Parallel multi-threading will find live hosts and open ports in
                                        seconds.

                                

                                

                                    

                                        Step 4: Inspect & Audit

                                    
Review hostnames,
                                        open ports, and click Send Notification to audit unaudited targets.

                                

                            

                        

                    


                    

                        

                            

                                
Network Scanner

                                
Discover live devices via port scanning — no agents required
                                

                            

                        


                        

                            Scans check ports: SSH (22), Telnet (23), HTTP (80), RPC (135), HTTPS (443), SMB (445),
                                RDP (3389), HTTP-Alt (8080), Printer (9100). Limit to /24 subnets for
                            best performance.
